# GitHub Profile Finder

A simple web app that searches GitHub profiles by username.

## How it works

1. Enter a GitHub username and select **Search**.
2. The app requests the profile from the GitHub API.
3. The profile picture, name, and number of public repositories appear. If the username is empty or the profile cannot be found, a message is shown.

## Run

Open `index.html` in a browser. An internet connection is required to fetch profile data.
